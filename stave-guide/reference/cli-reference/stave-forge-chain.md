# stave forge chain

Author and validate custom chains

## Usage

```
stave forge chain
```

## Description

Tools for validating and testing custom compound chain definitions.

Subcommands:
  lint    Validate chain YAML against catalog and capability vocabulary
  test    Test a chain against a snapshot

Exit Codes:
  0   Valid / test complete
  1   Errors found
  2   Invalid input

## Subcommands

| Command | Description |
|---|---|
| [`stave forge chain lint`](stave-forge-chain-lint.md) | Validate chain YAML |

# stave cel

CEL expression tools

## Usage

```
stave cel
```

## Description

Interactive CEL expression evaluation against observation data.

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands

| Command | Description |
|---|---|
| [`stave cel eval`](stave-cel-eval.md) | Evaluate a CEL expression against observation assets |

# stave forge

Author and test custom controls

## Usage

```
stave forge
```

## Description

Interactive tools for creating, previewing, and testing custom
security controls.

Subcommands:
  new       Interactive control authoring wizard
  preview   Evaluate a predicate against a snapshot without writing files
  paths     List available observation property paths from a snapshot

## Subcommands

| Command | Description |
|---|---|
| [`stave forge chain`](stave-forge-chain.md) | Author and validate custom chains |
| [`stave forge lint`](stave-forge-lint.md) | Static analysis for control YAML files |
| [`stave forge new`](stave-forge-new.md) | Interactive control authoring wizard |
| [`stave forge paths`](stave-forge-paths.md) | List available observation property paths from a snapshot |
| [`stave forge preview`](stave-forge-preview.md) | Evaluate a predicate against a snapshot without writing files |
| [`stave forge scaffold`](stave-forge-scaffold.md) | Generate test fixtures from a real snapshot |
| [`stave forge test`](stave-forge-test.md) | Run fixture-based assertions against a control |

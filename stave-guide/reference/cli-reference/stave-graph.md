# stave graph

Visualize control and asset relationships

## Usage

```
stave graph
```

## Description

Grouped graph commands: coverage, export.

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands

| Command | Description |
|---|---|
| [`stave graph coverage`](stave-graph-coverage.md) | Show which controls cover which assets |
| [`stave graph export`](stave-graph-export.md) | Export assessment as JSON, STIX 2.1, JSON-LD, or GraphML |

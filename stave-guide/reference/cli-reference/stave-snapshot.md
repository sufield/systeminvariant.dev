# stave snapshot

Snapshot inspection commands

## Usage

```
stave snapshot
```

## Description

Grouped snapshot commands: diff.

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands

| Command | Description |
|---|---|
| [`stave snapshot diff`](stave-snapshot-diff.md) | Compare the latest two observation snapshots |

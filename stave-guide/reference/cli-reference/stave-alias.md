# stave alias

Manage command aliases

## Usage

```
stave alias
```

## Description

Create, list, and delete command aliases stored in user config.

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands

| Command | Description |
|---|---|
| [`stave alias delete`](stave-alias-delete.md) | Delete an alias |
| [`stave alias list`](stave-alias-list.md) | List all aliases |
| [`stave alias set`](stave-alias-set.md) | Create or update an alias |

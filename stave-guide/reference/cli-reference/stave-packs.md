# stave packs

Inspect built-in control packs

## Usage

```
stave packs
```

## Description

Packs lists and shows embedded control packs available for deterministic offline evaluation.

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands

| Command | Description |
|---|---|
| [`stave packs list`](stave-packs-list.md) | List available built-in packs |
| [`stave packs show`](stave-packs-show.md) | Show one built-in pack and its control IDs |

# stave fingerprint

Policy fingerprint diagnostics

## Usage

```
stave fingerprint
```

## Description

Inspect and diagnose the policy fingerprint that certifies reproducibility.

|---|---|
| [`stave fingerprint explain`](stave-fingerprint-explain.md) | Show the policy fingerprint preimage and diagnosis |

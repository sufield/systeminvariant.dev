# stave generate

Generate starter artifacts

## Usage[​](#usage "Direct link to Usage")

```
stave generate
```

## Description[​](#description "Direct link to Description")

Generate creates minimal deterministic templates for observations.

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands[​](#subcommands "Direct link to Subcommands")

| Command                                                                                     | Description                      |
| ------------------------------------------------------------------------------------------- | -------------------------------- |
| [`stave generate observation`](/docs/reference/cli-reference/stave-generate-observation.md) | Generate an observation template |

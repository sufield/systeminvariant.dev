# stave config env

Manage environment variables

## Usage[​](#usage "Direct link to Usage")

```
stave config env
```

## Description[​](#description "Direct link to Description")

Env groups commands for discovering STAVE\_\* environment variables supported by Stave.

Examples: stave env list stave env list --format json

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands[​](#subcommands "Direct link to Subcommands")

| Command                                                                           | Description                                    |
| --------------------------------------------------------------------------------- | ---------------------------------------------- |
| [`stave config env list`](/docs/reference/cli-reference/stave-config-env-list.md) | List supported STAVE\_\* environment variables |

# stave forge chain

Author and validate custom chains

## Usage[​](#usage "Direct link to Usage")

```
stave forge chain
```

## Description[​](#description "Direct link to Description")

Tools for validating and testing custom compound chain definitions.

Subcommands: lint Validate chain YAML against catalog and capability vocabulary test Test a chain against a snapshot

Exit Codes: 0 Valid / test complete 1 Errors found 2 Invalid input

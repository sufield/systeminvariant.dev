# stave cel

CEL expression tools

## Usage[​](#usage "Direct link to Usage")

```
stave cel
```

## Description[​](#description "Direct link to Description")

Interactive CEL expression evaluation against observation data.

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands[​](#subcommands "Direct link to Subcommands")

| Command                                                             | Description                                          |
| ------------------------------------------------------------------- | ---------------------------------------------------- |
| [`stave cel eval`](/docs/reference/cli-reference/stave-cel-eval.md) | Evaluate a CEL expression against observation assets |

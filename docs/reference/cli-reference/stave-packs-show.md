# stave packs show

Show one built-in pack and its control IDs

## Usage[​](#usage "Direct link to Usage")

```
stave packs show <name>
```

## Description[​](#description "Direct link to Description")

Show details of a single built-in control pack including its control IDs, version, and description.

Exit Codes: 0 Success 2 Unknown pack name 4 Internal error

## Examples[​](#examples "Direct link to Examples")

```
stave packs show s3
  stave packs show s3 --output json
```

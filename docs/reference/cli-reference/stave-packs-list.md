# stave packs list

List available built-in packs

## Usage[​](#usage "Direct link to Usage")

```
stave packs list
```

## Description[​](#description "Direct link to Description")

List all built-in control packs embedded in the binary. Each pack is a curated set of controls for a specific domain (e.g. s3).

Exit Codes: 0 Success 4 Internal error

## Examples[​](#examples "Direct link to Examples")

```
stave packs list
  stave packs list --output json
```

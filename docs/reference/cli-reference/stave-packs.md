# stave packs

Inspect built-in control packs

## Usage[​](#usage "Direct link to Usage")

```
stave packs
```

## Description[​](#description "Direct link to Description")

Packs lists and shows embedded control packs available for deterministic offline evaluation.

Offline-only: reads local files; makes zero network connections; no cloud credentials.

## Subcommands[​](#subcommands "Direct link to Subcommands")

| Command                                                                 | Description                                |
| ----------------------------------------------------------------------- | ------------------------------------------ |
| [`stave packs list`](/docs/reference/cli-reference/stave-packs-list.md) | List available built-in packs              |
| [`stave packs show`](/docs/reference/cli-reference/stave-packs-show.md) | Show one built-in pack and its control IDs |

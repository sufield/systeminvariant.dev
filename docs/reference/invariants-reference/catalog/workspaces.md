# WORKSPACES controls (1)

### CTL.WORKSPACES.ENCRYPT.001[​](#ctlworkspacesencrypt001 "Direct link to CTL.WORKSPACES.ENCRYPT.001")

**WorkSpaces Must Encrypt Volumes At Rest**

* **Severity:** high
* **Type:** unsafe\_state
* **Domain:** encryption
* **Compliance:** nist\_800\_53\_r5: SC-28; soc2: CC6.7;

WorkSpaces root and user EBS volumes must be encrypted at rest.

**Remediation:** Enable volume encryption on the workspace.

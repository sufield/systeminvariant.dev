## What `gendocs` does

`gendocs` is a small Go program that imports the Stave CLI command package and walks the Cobra command tree to emit Docusaurus-compatible markdown for the CLI reference. It reads command metadata (`Use`, `Short`, `Long`, `Example`) and flag registrations directly from the compiled command objects — no scraping or manual parsing.

## Source

The generator lives at `stave/cmd/gendocs/main.go` and contains a `sidebarPosition` map to control sidebar ordering.

## Running it

- Automated (recommended): run the Make target from the `stave` directory:

```bash
make docs-gen
```

This builds `bin/gendocs` and runs it, writing files into `docs-content/cli-reference`.

- Manually:

```bash
go run ./cmd/gendocs [output-dir]
# default output-dir: ../docs-content/cli-reference
```

Or build then run the binary:

```bash
go build -o bin/gendocs ./cmd/gendocs
./bin/gendocs ../docs-content/cli-reference
```

## Output and conventions

The program writes `_index.md` plus one `stave-<command>.md` page per visible command into the chosen output directory. Each generated file includes the comment:

```
<!-- Auto-generated by gendocs. Do not edit. -->
```

Generated files are considered authoritative for the CLI reference and should not be edited by hand; re-run `make docs-gen` after adding or changing commands.

## Ordering and customization

To control the order of commands in the sidebar, edit the `sidebarPosition` map in `stave/cmd/gendocs/main.go`.

## Notes for CI / release pipelines

Docs and release pipelines call `go run cmd/gendocs/main.go` (or `make docs-gen`) as part of documentation generation. The `cmd/gendocs` tool is intended as a development/documentation helper and is excluded from certain production tests; see the `stave` Makefile for details.
